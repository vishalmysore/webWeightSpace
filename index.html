Language reference

<selector> <op> [args], one rule per line. Rules apply in order.

Selectors: * · embed · layers.10-13 · layers.*.mlp · layers.*.attn.o_proj · layers.0-5.*norm

Ops: mix a w += a·(donor − base) · scale k · zero · noise s · skip (zero o_proj + down_proj) · zero-heads 0-6 · inject word c (solve value-bias deltas so the layer writes c·unit(E[word]) into the residual stream) · steer concept c (rank-one down_proj edit from a vector pack, see the Diwali tab)
