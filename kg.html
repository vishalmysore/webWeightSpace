webWeightSpace

Can a model be edited to answer only with a knowledge graph? Two pieces work together here. A JSON schema (WebLLM's constrained decoding) guarantees the shape: both models can output nothing but {"triples":[{subject, predicate, object}]}. A rank-one weight edit to Llama-3.2-1B-Instruct then stands in for the system prompt that would normally say what a good triple is: it is the difference in the model's own hidden state with and without a "you are a knowledge-graph extractor" instruction, compiled into six layers. Neither model gets a system prompt. Download once (2.5 GB, shared with the other Llama tabs), then press Build & compare. A 1B model knows a limited number of facts and some triples will be wrong; this is a demo of model editing, not a knowledge-graph builder.
